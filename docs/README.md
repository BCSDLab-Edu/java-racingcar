구상 계획
1. player 이름을 한 문장으로 입력.
2. 입력받은 문장을 , 기준으로 분리
3. 이를 바탕으로 player 배열을 생성
3-1. player는 객체. 생성자는 이름 문자열을 입력받으며, 
     변수는 이름(string), 전진횟수(int)
3-2. 이 때 이름 문자는 5자 이하로만 생성. 
     이를 넘을 시 IllegalArgumentException 발생
4. 시도 횟수를 입력받음
 - 플레이어 목록을 가진 클래스 있으면 괜찮을거같음.
5. 각 시도 횟수마다 플레이어마다 전진여부를 결정. 
   이는 0~9 중 4 이상의 수를 뽑으면 전진하기로.
6. 각 시도의 결과를 매번 출력시 원하는 출력값이 나올거 같다.
7. 시도가 끝나면(마지막 시도의 결과는 6번에 따라 출력되어있음) 우승자 발표
7-2. 우승자는 여러명도 가능. 
     이 때 승자여부 변수가 있다면 승자여부 변수가 True인 player를 출력.
7-3. 승자는 각 플레이어의 전진 횟수가 가장 많은 플레이어를 승자로 판단.

구현 내용
-player 객체 (변수: String Name, int Movement)
-입력된 수에 따라 전진/정지 결정 메소드.(void - int)
-Game 객체 (변수: player[] players)
-이름 입력 시 올바른 이름인지 확인하는 메소드.(void - String[])
-매 attempt 마다 모든 플레이어에 대해 전진/정지 실행(void)
-해당 attempt의 player들의 누적 전진 횟수 출력(void)
-승자 확인 메소드(List<Player> - ) -배열보다는 추가 삭제에 용이한 리스트가 나을듯.
-승자 출력 메소드(void-List<Player>)
-총 실행 메소드(void)

-Application에서 Game 객체 생성 후 실행
