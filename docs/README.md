1. 입력 기능
    경주 할 자동차 이름(이름은 쉼표(,) 기준으로 구분, 5자 이하)
    시도할 횟수

2. 출력 기능
    각 차수별 실행 결과
        전진하는 자동차 이름 출력
    우승자 출력(우승자는 2명 이상 가능)

3. 게임 기능
    0 ~ 9 사이 랜덤 값을 구한 후 값이 4 이상일 경우 전진

    게임을 완료한 후 누가 많이 전진했는지 구하기

4. 오류 기능
   IllegalArgumentException 발생 후 종료
        이름이 6자 이상
        횟수가 숫자가 아닐 때
